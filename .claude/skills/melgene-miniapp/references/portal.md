# 포털 (apps/hub) 규칙

주소: `https://miniapp.melgene.com/` (melgene.com 에도 같은 포털, canonical 은 miniapp). 포털은 앱이 아니다 — 끝 화면·별점·공유 UI 가 없다.

## 화면 순서 (고정)

1. 공통 머리글: "Melgene + 언어별 배지"(누르면 같은 언어 포털 홈) · 언어 `<select>`
2. 작게 보이는 `<h1>` 한 줄: 브랜드 + 검색어 (예: "멜진 미니앱 · 무료 미니게임·심리테스트"). 숨긴 h1 금지
3. **오늘의 미니앱** 캐러셀 (제목 그대로: en "Today's Mini Apps", ja "今日のミニアプリ", zh "今日小应用", ko "오늘의 미니앱", fr "Mini-apps du jour", de "Mini-Apps des Tages", th "มินิแอปวันนี้", vi "Mini app hôm nay", es "Mini apps de hoy", it "Mini app di oggi", pt "Mini apps de hoje", ru "Мини-приложения дня"). 실제 누적 참여 수가 0보다 클 때만 제목 아래 한 줄
4. **모든 미니앱**: 카테고리 칩(전체·게임·심리테스트·만들기·투표) · 검색 · 정렬(**최신순 기본**·인기순·별점순 — 사용자 지시 2026-10-02, 처음 그리는 순서도 최신순) · 4칸 아이콘 격자(아이콘 + 이름, 아래 ♥·★)
5. **광고** `<div class="mg-ad"></div>` 1개 — 반드시 "모든 미니앱" 아래, FAQ 위
6. **자주 묻는 질문** (보이는 접이식, 4~6개)
7. 바닥글 (개인정보처리방침)

두지 않는 것: 히어로 문구("1분이면 끝나는 미니앱 모음" 류), 카테고리 설명 섹션(게임/심리테스트/만들기/투표 소개 글), 별도 소개(about) 섹션 — 소개 내용은 FAQ 로 합친다.

## 오늘의 미니앱 카드 — 위아래를 짧게

- 카드 높이 약 260px (375px 폭 기준). 아트 영역 148px, 모서리 24px.
- 키커 한 줄, 헤드라인 20px **최대 2줄**(line-clamp), 소개 13.5px **최대 2줄**, 아래 줄 = 앱 이름 + ♥·★·참여 + "지금 하기" 버튼.
- 문구는 `apps/hub/tools/i18n/<lang>.js` 의 `curation.items[{ id, kicker, headline, blurb }]`. 소개는 2줄 안에 들어가게 짧게 쓴다(대략 ko 45자, ja 32자, 라틴 70자 이내). 넘치면 `check-hub.js --layout` 이 실패한다 — 말줄임으로 두지 말고 문구를 줄인다.
- 스포일러 금지: 헤드라인·소개에 실제 질문·결과를 인용하지 않는다. 분위기·하는 법만.

## 숫자·정렬

- 모든 숫자는 Supabase `app_summary()` 실제 값. 없으면 숨김/"새로 나왔어요".
- 기본 정렬 = 최신순(added 늦은 앱 먼저, 같은 날은 order 순). 끝 화면 "다른 미니앱" 목록도 최신순.
- 인기순 = `score` (하트×10 + 별점 합 + 플레이) → 하트 → 플레이 → 최신. 등록 14일 이내 NEW 배지(`SITES[].added`).
- 줄임 표기는 언어별(1.2万·1.2만·12 k·1,2 Mio.·12 N·12 mil·it 12.345/1,2 Mln·pt 12 mil/1,2 mi·ru 12 тыс./1,2 млн), 항상 내림.

## 포털 FAQ

- 포털만 예외로 보이는 FAQ + FAQPage JSON-LD (+ WebSite + ItemList).
- 넣지 않는 질문: "정말 무료인가요?", "인기순·하트·별점은 어떻게 정해지나요?" 같은 운영 설명.
- 넣는 질문 예: 멜진 미니앱은 어떤 곳인가요? / 앱을 설치하거나 가입해야 하나요? / 개인정보를 모으나요? / 새 미니앱은 얼마나 자주 나오나요? — 답에 현지 검색어(미니게임·심리테스트·미니앱)를 자연스럽게.

## 확인

`node apps/hub/tools/gen-i18n.js && node apps/hub/tools/check-hub.js --layout` (구조·브랜드·SEO·스포일러·순서 + 12개 언어 360/375 실측: 넘침, 헤드라인·소개 2줄, 머리글 겹침). 포털 OG 는 SITES 이름을 쓰므로 이름을 바꾸면 `node apps/hub/tools/gen-og.js`.
