# apps/sled — 썰매 레이스 (게임)

썰매 레이스(Sled Race, そりレース, 雪橇竞速, Гонка на санках). **위에서 내려다본 끝없는 눈 언덕을 썰매로 내려가며 장애물을 피하고, 모을 것을 줍고, 점프대로 날아오르는 90초 게임.** 그림은 모두 코드로 그린다(썰매·아이·소나무·바위·눈사람·깃발·선물·별·점프대, 저작권 캐릭터 없음).
- 조종: 필드 왼쪽/오른쪽 절반을 누르고 있기(방향 dir), 누른 채 옆으로 12px 넘게 끌기(끈 만큼 목표 x — 손가락을 따라감), ←/→·A/D 누르고 있기. 옆 속도가 목표(±MAX_VX 260)를 STEER_RESP 로 따라간다. 양 끝은 막힐 뿐.
- 썰매는 화면 위쪽(SLED_Y 180)에 고정, 세계가 위로 흐른다. 속도는 시간에 따라 210 → 500 단위/초(75초에 최대).
- 장애물: 소나무·바위·눈사람(충돌 반지름 = 그림 × 0.78). 닿으면 하트 −1, 1.6초 무적(깜빡임), 속도 × 0.55 뒤 회복. 하트 3개를 다 잃으면 끝(crash).
- 모을 것: 깃발 +10 · 선물 +30 · 황금 별 +100(드묾, 점프대 줄 근처에서 조금 더 자주). 점프대: 땅에서 가운데로 지나면 0.95초 공중(장애물 무시) + 20점.
- 코스: 줄(row) 단위로 미리 만든다. 줄마다 안전한 길(path) 양쪽 corr(60 → 46) 안에는 장애물을 두지 않고, 다음 줄 길은 썰매가 따라갈 수 있는 만큼만 움직인다 — 언제나 지나갈 수 있다(check 가 자동 조종 40판 무사고 완주로 확인). 점프대는 9~14줄마다 길 위에, 그다음 줄은 장애물 하나 더.
- 점수 = floor(거리 / 40) + 보너스(모은 것·점프). 거리(m) = 단위 / 10. 90초에 결승선(finish).
- 결과 = 점수 + 끝난 이유(결승선/넘어짐) + 거리 + 모은 것 + 점프 + 등급(6단계 중 내 것만: 0·500·1100·1700·2400·3100점) + 내 최고 + 서버 실제 백분위.
  - 등급 경계는 봇으로만 맞췄다: 완벽한 자동 조종 평균 약 2,780점(최고 약 3,600), 반응이 250ms 늦는 봇 약 2,500점, 400ms 늦고 가끔 엉뚱하게 꺾는 봇 약 1,260점.
시작(티징 + 짧은 방법 3칸 + 맨 아래 광고 1개) → 게임(HUD 점수·거리·하트·일시정지 + 남은 시간 막대 + 캔버스, 광고 없음) → 끝 화면(결과 카드 → 공통 끝 화면).

- 흐름: 시작 버튼 = 준비 상태("탭해서 출발"), **첫 입력(필드 누르기·방향키)이 판을 시작하고 `track('start')`**, 끝 화면에 닿을 때 `track('done')`. 다시 하기 = 새 준비 상태.
- 고정 시간 간격(1/120초 tick, 큰 dt 는 100ms 로 자름) → 같은 시드 + 같은 입력 = 같은 판. 난수 = crypto 시드 mulberry32.
- 탭을 떠나면(visibilitychange·pagehide) 자동 일시정지(시계도 멈춤), P/Esc 일시정지.
- `prefers-reduced-motion`: 내리는 눈 적게·멈춤, 눈보라·흔들림·번쩍임·떠오르는 글자 움직임 끔, 끝 화면까지 0.45초.
- 숫자는 진짜만: `supa.submitScore('sled', bucket)` 한 번, bucket = min(600, floor(점수 / 10)). **`C.plausible(s)` 가 거짓이면(90초를 다 채우지 않은 finish·하트가 남은 crash·6000점 초과·최고 속도로도 못 가는 거리·모은 것과 보너스 불일치) 보내지 않는다.** 서버 없음·실패·비교할 기록 없음 → 백분위 칸 통째로 숨김.
- 최고 기록: localStorage `sled_best_v1`.
- 검사용 핸들 `window.SLED_APP` (phase, state, best, timeScale, steer(dir), target(x), autopilot, begin).

주소: 원본은 자리표시자 `https://sled.example.com/`, 배포 때 `https://melgene.com/sled/`. 규칙은 `.claude/skills/melgene-miniapp/SKILL.md`.
