วิธีสร้าง QR Code ที่สแกนติดทุกครั้ง

อัปเดต 11 ตุลาคม 2569

QR Code อยู่รอบตัวเรา ทั้งบนโต๊ะร้านอาหาร บัตรคอนเสิร์ต กล่องพัสดุ และโปสเตอร์ ดูเผินๆ เหมือนจุดกระจัดกระจาย แต่ทุกช่องมีหน้าที่ของมัน คู่มือนี้จะอธิบายว่า QR Code เก็บอะไรไว้จริงๆ วิธีสร้างโค้ดสำหรับลิงก์ ข้อความ หรือ Wi-Fi วิธีพิมพ์ให้สแกนติดตั้งแต่ครั้งแรก ที่มาของ QR Code และข้อควรระวังเมื่อสแกนโค้ดที่คนอื่นทำ

QR Code คืออะไร

QR ย่อมาจาก Quick Response แปลว่าตอบสนองรวดเร็ว QR Code เป็นบาร์โค้ดสองมิติ แทนที่จะเป็นแถบเส้นแถวเดียว มันเก็บข้อมูลไว้ในตารางสี่เหลี่ยมของช่องสีเข้มและสีอ่อนที่เรียกว่าโมดูล สี่เหลี่ยมใหญ่สามมุมคือรูปแบบระบุตำแหน่ง บอกกล้องว่าโค้ดอยู่ตรงไหน หมุนไปเท่าไร และใหญ่แค่ไหน เราจึงสแกนกลับหัวหรือเอียงก็ได้

ช่องที่เหลือเก็บข้อมูลของเรา พร้อมข้อมูลแก้ไขข้อผิดพลาดที่คำนวณด้วยรหัสรีด–โซโลมอน ซึ่งเป็นคณิตศาสตร์แบบเดียวกับที่ใช้ในแผ่นซีดีและยานสำรวจอวกาศ เพราะมีข้อมูลสำรองนี้ ตัวอ่านจึงกู้เนื้อหาคืนได้แม้โค้ดบางส่วนจะเปื้อน ขาด หรือถูกบัง เวอร์ชันเล็กสุดคือเวอร์ชัน 1 ขนาด 21×21 โมดูล ใหญ่สุดคือเวอร์ชัน 40 ขนาด 177×177 โมดูล เก็บได้เกือบสามพันไบต์ เนื้อหายิ่งยาว ตารางก็ยิ่งใหญ่และถี่ขึ้น

สร้าง QR Code ที่นี่อย่างไร

เครื่องมือนี้ทำงานในเบราว์เซอร์ทั้งหมด โค้ดถูกคำนวณบนอุปกรณ์ของคุณทันทีที่พิมพ์ จึงไม่มีการอัปโหลด บันทึก หรือเก็บข้อมูลที่คุณกรอก และไม่ต้องสมัครสมาชิก

  • เลือกสิ่งที่จะใส่ในโค้ด: ลิงก์ ข้อความ Wi-Fi อีเมล หรือเบอร์โทร
  • กรอกข้อมูล ถ้าพิมพ์ที่อยู่เว็บโดยไม่มี https:// ระบบจะเติมให้อัตโนมัติ มือถือจะได้เปิดเป็นลิงก์
  • ดูตัวอย่างแบบเรียลไทม์ เปิดตัวเลือกเพื่อเปลี่ยนสี ระดับแก้ไขข้อผิดพลาด ขนาดรูป หรือขอบว่าง
  • ดาวน์โหลด PNG สำหรับหน้าจอและเอกสาร หรือ SVG สำหรับงานพิมพ์ ในเบราว์เซอร์ที่รองรับยังคัดลอกรูปไปคลิปบอร์ดได้ทันที
  • สแกนด้วยมือถือของตัวเองก่อนแชร์หรือพิมพ์

QR Code Wi-Fi สำหรับแขก

QR Code Wi-Fi ช่วยให้แขกไม่ต้องพิมพ์รหัสผ่านยาวๆ มันเก็บชื่อเครือข่าย รหัสผ่าน และการเข้ารหัสในรูปแบบข้อความมาตรฐานที่ขึ้นต้นด้วย WIFI: แอปกล้องในตัวของ iPhone และ Android รู้จักรูปแบบนี้ และจะเสนอให้เชื่อมต่อด้วยการแตะครั้งเดียว

เลือกการเข้ารหัสให้ตรงกับเราเตอร์ เราเตอร์รุ่นใหม่เกือบทั้งหมดใช้ WPA2 หรือ WPA3 ซึ่งอยู่ในกลุ่ม WPA ทั้งคู่ เลือก "ไม่มีรหัสผ่าน" เฉพาะเครือข่ายเปิด และติ๊ก "เครือข่ายซ่อน" ถ้าเราเตอร์ไม่ประกาศชื่อ อักขระพิเศษอย่างเครื่องหมายอัฒภาค จุลภาค ทวิภาค และอัญประกาศจะถูกจัดการให้อัตโนมัติ ถ้าเปลี่ยนรหัส Wi-Fi ภายหลัง ต้องสร้างโค้ดใหม่ เพราะโค้ดเก่าจะใช้ไม่ได้แล้ว

เคล็ดลับการพิมพ์: ขนาด ความต่างของสี และการแก้ไขข้อผิดพลาด

ปัญหาสแกนไม่ติดส่วนใหญ่มาจากการพิมพ์ ไม่ใช่ตัวโค้ด ทำตามกฎง่ายๆ ไม่กี่ข้อก็ช่วยได้มาก

  • ขนาด: โดยทั่วไปโค้ดควรกว้างอย่างน้อยหนึ่งในสิบของระยะสแกน โค้ดที่สแกนจากระยะ 30 ซม. ควรกว้างราว 3 ซม. ส่วนโปสเตอร์ที่มองจากระยะ 3 เมตรควรกว้างราว 30 ซม.
  • ความต่างของสี: ใช้โค้ดสีเข้มบนพื้นสีอ่อน ดำบนขาวปลอดภัยที่สุด สีซีด สีไล่เฉด และโค้ดสีอ่อนบนพื้นเข้มทำให้แอปสแกนหลายตัวงง เครื่องมือจึงเตือนเมื่อสีตัดกันน้อย
  • ขอบว่าง: เว้นขอบว่างรอบโค้ด มาตรฐานกำหนดสี่โมดูล ตัวอักษรหรือรูปที่ชิดขอบเกินไปเป็นสาเหตุที่พบบ่อยของการสแกนไม่ติด
  • ระดับแก้ไขข้อผิดพลาด: L กู้ความเสียหายได้ราว 7% M ราว 15% Q ราว 25% และ H ราว 30% ใช้ M ในงานทั่วไป ใช้ Q หรือ H กับสติกเกอร์ ป้ายกลางแจ้ง หรือโค้ดที่มีโลโก้เล็กๆ วางทับ และใช้ L เมื่ออยากใส่ข้อความยาวในโค้ดเล็กบนหน้าจอ
  • ความยาวเนื้อหา: ที่ขนาดพิมพ์เท่ากัน เนื้อหาสั้นจะได้โมดูลใหญ่กว่า จึงควรใช้ลิงก์สั้นแทนที่อยู่ยาวเหยียด

ประวัติสั้นๆ ของ QR Code

QR Code ถูกคิดค้นในปี 1994 โดยมาซาฮิโระ ฮาระและทีมที่เดนโซ่ เวฟ ซึ่งตอนนั้นเป็นแผนกหนึ่งของเดนโซ่ บริษัทผลิตชิ้นส่วนรถยนต์ญี่ปุ่นในเครือโตโยต้า โรงงานรถยนต์ติดตามชิ้นส่วนด้วยบาร์โค้ดธรรมดา และคนงานต้องสแกนหลายฉลากต่อกล่อง เพราะบาร์โค้ดหนึ่งอันเก็บได้แค่ราวยี่สิบตัวอักษร ฮาระต้องการโค้ดที่เก็บข้อมูลได้มากกว่ามากและอ่านได้เร็วจากทุกทิศทาง

สี่เหลี่ยมระบุตำแหน่งถูกออกแบบให้มีสัดส่วนขาวดำที่แทบไม่พบในตัวหนังสือหรือภาพพิมพ์ เครื่องสแกนจึงหาเจอทันที เดนโซ่ เวฟถือสิทธิบัตรแต่เลือกไม่บังคับใช้ และรูปแบบนี้กลายเป็นมาตรฐานสากล ISO ในปี 2000 เมื่อกล้องสมาร์ตโฟนอ่าน QR Code ได้เอง มันก็แพร่ไปสู่การจ่ายเงิน บัตรขึ้นเครื่อง เมนูอาหาร และอีกมากมาย ชื่อ QR Code ยังคงเป็นเครื่องหมายการค้าจดทะเบียนของเดนโซ่ เวฟ

สแกนอย่างปลอดภัย

QR Code เป็นแค่ภาชนะ และใครก็พิมพ์ได้ มิจฉาชีพบางรายแปะสติกเกอร์โค้ดปลอมทับโค้ดจริงที่ตู้จ่ายค่าจอดรถ โปสเตอร์ หรือโต๊ะร้านอาหาร เพื่อพาคนไปหน้าชำระเงินหรือหน้าล็อกอินปลอม ก่อนเปิดลิงก์ ให้อ่านที่อยู่ที่กล้องแสดงและตรวจว่าเป็นของร้านที่ตั้งใจจริง ระวังโค้ดที่ขอข้อมูลบัตร รหัสผ่าน หรือให้ติดตั้งแอป และอย่าสแกนโค้ดจากข้อความแปลกหน้าที่เร่งให้รีบทำ

เวลาสร้างโค้ดเองก็ใช้หลักเดียวกัน ใช้ลิงก์ที่คุณดูแลเอง ทดสอบก่อนพิมพ์ และถ้าติดไว้ในที่สาธารณะ หมั่นตรวจดูว่าไม่มีใครเอาสติกเกอร์มาแปะทับ
