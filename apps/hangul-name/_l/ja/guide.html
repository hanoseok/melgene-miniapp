名前を韓国語(ハングル)に：ハングルのしくみと名前の書き方

更新日 2026年10月9日

自分の名前を別の文字で見るのは、ちょっとうれしい体験です。とくにハングルは音をブロックのように組み立てる文字なので、名前を書いてみるのにぴったり。このガイドでは、ハングルとは何か、なぜ韓国では毎年10月9日を祝うのか、文字がどう音節ブロックになるのか、そしてMichaelやさくらのような名前がどうハングルになるのかを説明します。同じ名前でも書き方が何通りかある理由や、名前を長く残るものに使う前に確かめたいことも紹介します。

ハングルとは？どうやって生まれた？

ハングルは韓国語を書くための文字です。それ以前、朝鮮では漢字を借りて文章を書いていましたが、覚えるのに何年もかかり、韓国語の言葉にもうまく合わなかったため、多くの庶民は読み書きができませんでした。朝鮮王朝の世宗大王はこれを変えようと、1443年に学者たちと新しい文字を完成させ、1446年に『訓民正音』という書物で公布しました。訓民正音とは「民を教える正しい音」という意味です。

ハングルはとても論理的な文字として知られています。子音の形は、その音を出すときの口・舌・のどの形をかたどり、強い音には画を1本足します。母音は天・地・人を表す点、横線、縦線の3つを組み合わせて作られました。世宗は「賢い人なら朝のうちに覚えられる」と語ったと伝えられ、今の学習者も実際にすぐ読み始めることが多いです。

10月9日はハングルの日

韓国では『訓民正音』の公布にちなむ10月9日を「ハングルの日（ハングルラル）」として祝います。祝日で、展示や書道イベントが開かれ、美しい文字に注目が集まる日です。北朝鮮は1月15日を独自の記念日にしています。『訓民正音』の解例本はユネスコの世界の記憶に登録され、ハングルは世界でもっともよく設計された文字のひとつとしてよく紹介されます。

そのため10月の初めには、世界中で自分の名前をハングルで調べたり、書道をまねしてみたり、友だちにハングルの名前カードを送ったりする人が増えます。このツールはまさにそんな楽しみのために作りました。

音節ブロックのしくみ

現代のハングルは、基本の子音14個と母音10個、さらに濃音や合成母音でできています。英語のように文字を横に並べるのではなく、四角いブロックにまとめて書き、ひとつのブロックが1音節になります。ブロックは必ず子音で始まり、次に母音が来て、最後にパッチムと呼ばれる終わりの子音が付くこともあります。

母音で始まる音節では、音のない丸い文字が最初の位置を埋めます。だからエンマ（Emma）のハングルは丸で始まります。縦長の母音は最初の子音の右に、横長の母音は下に置き、パッチムはいちばん下に来ます。結果画面ではMichaelを ma-i-keul のようにブロックごとの読み方で表示するので、1文字ずつ声に出して読めます。

  • 子音＋母音：ma や so のような開いたブロック
  • 子音＋母音＋パッチム：min や keul のような閉じたブロック
  • 音のない丸＋母音：i や a のように母音で始まるブロック

外国の名前がハングルになる方法

韓国語では名前を意味で訳さず、音で書き表します。これを音訳といいます。韓国の国立国語院は外来語の表記ルールを定めていて、新聞や出版社もそれに従います。よくある名前には決まった表記があるので、このツールはまず Michael、Sophia、Smith、Garcia のような名前や名字の辞書を調べます。

辞書にない名前は、つづりを音の単位に分け、sh・ch・th・ee などの文字の組み合わせを処理してから、ブロックをひとつずつ組み立てます。公式ルールのいくつかにも従います。後ろに母音のない子音には「ウ」のような弱い母音を付けるので Smith は3文字になり、音節の終わりの r はイギリス英語のように読まないことが多く、母音にはさまれた l は二重に書きます。ひらがな・カタカナは日本語の表記表で変換し、キリル文字はいったんローマ字に直してから変換します。

同じ名前でも書き方が何通りもある理由

韓国語には f と v の区別がなく、l と r も同じ文字で書くなど、音の種類が少ない部分があるので、違う名前が似た表記になることがあります。さらに同じつづりでも英語・フランス語・スペイン語・ドイツ語で発音が違い、ハングルはその音に合わせます。有名人やブランドがルールと違う昔からの表記を使うこともあるので、別の場所で少し違う表記を見かけても、どちらも正しい場合があります。

家族が呼ぶ発音と結果が違うと感じたら、聞こえるとおりに入力し直してみてください。John を Jon に、Anna を Ana にするなど少し変えるだけで、実際の発音に近い表記になることがあります。

カード・タトゥー・贈り物に使うときのコツ

ハングルの名前カードは、ハングルの日のお祝いやプロフィールの飾り、韓国の友だちとの会話のきっかけにぴったりです。カードのスタイルを選んで画像を保存し、リンクをシェアすれば友だちも同じカードを見られます。入力した名前はサーバーに送られず、すべてブラウザの中で処理されます。

  • タトゥー・刻印・印刷する贈り物に使う前に、必ず韓国語ネイティブに表記と文字を確認してもらいましょう。
  • 友だちにもカードを作ってもらい、名前を並べて比べてみましょう。
  • 本名、ニックネーム、好きなキャラクターの名前を入れて、ブロックの形の違いを見てみましょう。
  • カードの下に出るブロックの順番をまねして、手書きで名前を練習してみましょう。
