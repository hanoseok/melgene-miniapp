# apps/reindeer — 순록 점프 (게임)

순록 점프(Reindeer Jump, トナカイジャンプ, 驯鹿跳跃, Прыжки оленя). **옆에서 본 눈 덮인 밤 지붕(canvas, 가로 스크롤)을 순록이 끝없이 달리고, 버튼 하나로 점프하는 원버튼 러너.** 그림은 모두 코드로 그린다(순록·굴뚝과 연기·눈 더미·얼음·까마귀·선물·황금 방울·건물과 창문·달·별, 저작권 캐릭터 없음 — 루돌프·산타 이름/그림 없음).
- 점프(한 버튼): 필드 어디든 누르기 · 스페이스/↑/W. 누르는 순간 땅이면 점프(JUMP_V 640), 공중이면 한 번 2단 점프(DJUMP_V 560). 올라가는 동안 누르고 있으면 중력이 약해(G_HOLD 1500, 아니면 G_FALL 2900) 길게 = 높이(약 134), 톡 = 낮게(약 68). 코요테 90ms(지붕 끝 직후 점프), 착지 버퍼 120ms. 한 프레임 안에 눌렀다 떼도 톡 점프 한 번.
- 순록은 화면 x 86 에 고정, 세계가 왼쪽으로 흐른다. 속도 250 → 520 단위/초(150초에 최대), 부딪혀도 느려지지 않음(만든 뒤 속도는 오르기만 함).
- 지붕 사이 틈에 빠지면(발이 지붕보다 8 아래) 바로 끝(fall). 굴뚝(높이 40→62, 연기는 장식)·눈 더미·얼음·까마귀(머리 높이, 27초 뒤부터)에 닿으면 하트 −1, 1.5초 무적(깜빡임). 하트 3개를 다 잃으면 끝(crash).
- 모을 것: 선물 +10(위험 사이 달리는 구간) · 황금 방울 +50(굴뚝·까마귀·틈 위, 길게 누른 점프 꼭대기에서만 닿음). 거리 20 단위 = 1 m = 1점.
- 코스 보장: 위험(틈·장애물)마다 "꼭대기가 위험 한가운데 오도록 길게 누른 점프"(JUMP 표 — 코어가 tick 으로 직접 잼)로 넘을 수 있게 만든다. 틈 폭 ≤ 0.72 × 지금 속도 × 공중 시간(0.73초), 위험 사이 간격 ≥ 착지 → 다음 도약 0.14초 달리기(9초 뒤 속도 vHi 기준). check 가 물리 계산(가장 높은 장애물·가장 넓은 장애물·틈 상한) + 자동 점프 40판 × 180초 무사고 + 만들어진 위험 4,900여 개를 도착 속도로 다시 계산(틈 ≤ 점프 거리의 68%, 장애물 위 머무는 시간, 착지 → 다음 도약 간격 ≥ 0.16초)해 확인.
- 점수 = floor(거리 / 20) + 보너스. 결과 = 점수 + 끝난 이유(틈/하트) + 거리 + 선물 + 방울 + 등급(6단계 중 내 것만: 0·300·800·1600·3000·5500점) + 내 최고 + 서버 실제 백분위.
  - 등급 경계는 봇으로만 맞췄다: 완벽한 자동 점프 180초 약 5,800점, 타이밍 오차 ±120ms 봇 중앙값 약 4,000점, ±170ms 약 1,800점, ±230ms 약 1,000점.
시작(티징 + 짧은 방법 3칸 + 맨 아래 광고 1개) → 게임(HUD 점수·거리·하트·일시정지 + 캔버스, 광고 없음) → 끝 화면(결과 카드 → 공통 끝 화면).

- 흐름: 시작 버튼 = 준비 상태("톡 쳐서 출발"), **첫 입력(필드 누르기·스페이스/↑)이 판을 시작하고 `track('start')`**(그 입력으로는 뛰지 않음), 끝 화면에 닿을 때 `track('done')`. 다시 하기 = 새 준비 상태.
- 고정 시간 간격(1/120초 tick, 큰 dt 는 100ms 로 자름) → 같은 시드 + 같은 입력 = 같은 판. 난수 = crypto 시드 mulberry32.
- 탭을 떠나면(visibilitychange·pagehide) 자동 일시정지(시계도 멈춤), P/Esc 일시정지.
- `prefers-reduced-motion`: 내리는 눈 적게·멈춤, 굴뚝 연기·별 반짝임·흔들림·번쩍임·떠오르는 글자 움직임 끔, 끝 화면까지 0.45초.
- 숫자는 진짜만: `supa.submitScore('reindeer', bucket)` 한 번, bucket = min(20000, floor(점수 / 10)). **`C.plausible(s)` 가 거짓이면(최고 속도로도 못 가는 거리·모은 것과 보너스 불일치·1초에 4개 넘게 모음·하트가 남은 crash·하트를 잃은 수와 맞지 않는 fall·200,000점 초과) 보내지 않는다.** 서버 없음·실패·비교할 기록 없음 → 백분위 칸 통째로 숨김.
- 최고 기록: localStorage `reindeer_best_v1`.
- 검사용 핸들 `window.REINDEER_APP` (phase, state, best, timeScale, hold(on), autopilot, begin).

주소: 원본은 자리표시자 `https://reindeer.example.com/`, 배포 때 `https://melgene.com/reindeer/`. 규칙은 `.claude/skills/melgene-miniapp/SKILL.md`.
