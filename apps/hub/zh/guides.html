玩法攻略与技巧

每篇攻略都会讲清楚小应用怎么玩、怎样玩得更好，以及开始前值得知道的小知识。绝不剧透，题目和结果留给你亲自揭晓。

  • 💯 百分比计算器算出某数的百分之几、占比多少、增长率与下降率、打折价与省下的钱、原价反推、百分点差，边输入边出结果并显示算式。阅读攻略 → 去玩
  • 🏁 动物赛跑抽签输入名字，每人一只小动物各占一条跑道。第一名胜出，或者最后一名请喝咖啡。名次由公平随机决定。阅读攻略 → 去玩
  • 🐍 贪吃蛇滑动屏幕或用方向键控制小蛇，吃苹果变长，小心别撞墙或咬到自己的尾巴。越吃越快的经典贪吃蛇。阅读攻略 → 去玩
  • 🏠 宅度测试10个日常场景，1分钟测出你的宅度是多少百分比。阅读攻略 → 去玩
  • 🎂 年龄计算器输入出生日期，算出精确到年、月、天的周岁，下次生日倒数、已活天数、出生星期、星座和生肖，还有一万天纪念日。阅读攻略 → 去玩
  • 🍾 转瓶子把手机放在桌子中间转瓶子。把大家的名字围成一圈，公平决定谁先来、谁来点歌。阅读攻略 → 去玩
  • ⚾ 猜数字根据位置对、数字对的提示，猜出电脑设定的 3 位或 4 位数字。次数越少越好，还能看真实排名。阅读攻略 → 去玩
  • 💸 消费性格测试是会攒钱的，还是爱犒劳自己的？12个日常花钱场景，约2分钟，测出你的花钱类型，轻松好玩。阅读攻略 → 去玩
  • 📅 倒数日计算器倒数到任何日子、计算在一起第几天（100天、1000天、周年），还能日期加减。实时倒计时卡片可保存分享。阅读攻略 → 去玩
  • 🎟️ 抽签手机传一圈，每人抽一张折好的纸签。中签、空签或自定义奖项都行，最后清楚列出谁抽到了什么。阅读攻略 → 去玩
  • 🃏 记忆翻牌翻开万圣节卡牌，找出所有相同的图案。三种难度，记录用时和步数，看看你的真实排名。阅读攻略 → 去玩
  • ⚡ 泰托埃根测试你是泰托（Teto）还是埃根（Egen）？12个日常情境，2分钟测出你的能量比例。阅读攻略 → 去玩
  • 📝 字数统计粘贴文本即可实时统计含空格/不含空格字数、词数、句数和字节数。目标字数进度条和阅读时间，不上传任何内容。阅读攻略 → 去玩
  • 🎱 是或否决定器写下让你纠结的问题，按一下就得到是或否。还有是/否/也许、神秘水晶球回答和三局两胜、五局三胜。阅读攻略 → 去玩
  • 🔢 1到50 舒尔特方格按顺序尽快点击1到50！计时精确到0.01秒，还有1到25快速模式，测测你的专注力和手速。阅读攻略 → 去玩
  • 🧟 丧尸末日生存测试丧尸爆发了！12个情境，2分钟测出末日里你会扮演什么角色。阅读攻略 → 去玩
  • 🔑 密码生成器选好长度和字符类型，立即生成高强度随机密码或好记的单词口令。显示真实强度和破解时间，不上传任何数据。阅读攻略 → 去玩
  • 🪑 随机排座位输入名单就能随机排座位。可设行列、空位、不坐一起的同学、固定座位和前排座位，公平打乱。阅读攻略 → 去玩
  • 🔢 数独让每行、每列、每个九宫格都填满1到9。简单到专家四种难度，支持笔记、提示和每日一题。阅读攻略 → 去玩
  • 🧩 MBTI测试20道日常小题，3分钟测出你是16型人格中的哪一型，还能看到每个维度的比例。阅读攻略 → 去玩
  • 🔳 二维码生成器把网址、文字、Wi-Fi、邮箱或电话号码马上变成二维码。可选颜色和尺寸，保存为PNG或SVG，内容不会上传服务器。阅读攻略 → 去玩
  • 🔢 随机数生成器设定最小值和最大值，就能公平抽出1到1000个随机数。可选不重复、排除号码、排序，还能分享抽奖结果链接。阅读攻略 → 去玩
  • 💣 扫雷根据数字推理，避开地雷清空雷区。三种难度，第一下必定安全，还能挑战最快用时。阅读攻略 → 去玩
  • ☕ 咖啡性格测试12道日常小题，2分钟测出和你性格最像的咖啡。阅读攻略 → 去玩
  • 🔤 名字翻译成韩文输入名字，马上变成韩文（谚文）写法，每个字都附读音，还能存成漂亮的名字卡片分享。阅读攻略 → 去玩
  • 🎲 掷骰子一次掷1到6个骰子。普通六面骰之外还有d4、d8、d10、d12、d20，马上显示点数合计和最近10次记录。阅读攻略 → 去玩
  • 🧱 打砖块用挡板把球弹回去，砸碎一排排霓虹砖块。三条命，关卡越来越快，你能闯几关？阅读攻略 → 去玩
  • 🧠 心理年龄测试周末早晨、群聊、下雨的假日……12道日常小题，2~3分钟测出你的心理年龄。阅读攻略 → 去玩
  • ✨ 花式字体生成器输入文字，一键变成粗体、手写体、圆圈字、颠倒等花式字体，点一下即可复制，中文也能加装饰。阅读攻略 → 去玩
  • 🎱 彩票号码生成器韩国乐透6/45、欧洲式、美国强力球或自定义范围，随手摇一组幸运号码。可固定或排除号码，一次最多5注，附彩球滚动动画，仅供娱乐。阅读攻略 → 去玩
  • 🔨 打地鼠地鼠从洞里冒头就快点一下，遇到炸弹别碰，30秒内冲高分、拿称号。阅读攻略 → 去玩
  • 🦊 你是什么动物测试从临时放鸽子到半夜来电，8个日常小场景，2~3分钟测出和你最像的动物。阅读攻略 → 去玩
  • 🏷️ 昵称生成器选一种风格，再输入名字，就能得到专属昵称。不满意可以反复重抽，满意后一键复制。阅读攻略 → 去玩
  • 🪙 抛硬币正面还是反面，抛一枚硬币马上决定。两面的名字可以自己改，也可以掷1到3个骰子。阅读攻略 → 去玩

  • 💘 恋爱类型测试从暧昧到约会再到小争吵，10个恋爱小场景，2~3分钟测出你是哪种恋人。阅读攻略 → 去玩
